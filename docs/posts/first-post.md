## 为什么选择 VitePress？

VitePress 是一个现代的静态网站生成工具，具有以下优势：

1. **快速** - 基于 Vite 构建
2. **简单** - 使用 Markdown 编写
3. **强大** - 支持 Vue 组件

## 开始使用

现在你可以开始在 `docs` 文件夹中创建你的内容了！

```bash
npm run dev    # 启动开发服务器
npm run build  # 构建静态网站
```
