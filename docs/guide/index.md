# 站点说明

这个站点用于整理工作中的零散随记，把临时记下来的命令、排障结论和经验判断，转成更适合长期阅读的文章。

## 内容原则

- 只保留可复用的知识点。
- 不公开账号、口令、密钥、内网地址等敏感信息。
- 尽量把“怎么做”升级成“为什么这样做”。

## 当前整理方向

- Spring Boot 启动、调试与部署
- Windows / Linux 日常运维命令
- Docker、Nginx、NSSM 这类基础设施经验
- 时区、日志、Elasticsearch 等常见疑难问题
